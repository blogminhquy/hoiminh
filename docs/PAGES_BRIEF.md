# Brief dựng màn hình web Hội Mình (apps/web)

Bạn viết các trang React cho `apps/web` (React 18 + Vite + React Router 6 + TanStack Query 5 + Tailwind). Repo: `D:\HoiMinh`. Mọi chữ trên giao diện bằng **tiếng Việt**.

## Nguồn sự thật giao diện
`D:\HoiMinh\design\build.mjs` chứa markup từng màn hình (template string HTML với token màu `T`). **Tái tạo đúng bố cục, màu, chữ, icon của màn hình được giao** (đọc đúng đoạn dòng ghi ở nhiệm vụ). Không tự nghĩ giao diện khác. Số liệu trong demo chỉ là dữ liệu mẫu: trang thật lấy số liệu từ API.

## Quy ước bắt buộc
- TypeScript strict, **không dùng `any`** (dùng kiểu cụ thể; nếu cần `Record<string, unknown>`), `noUncheckedIndexedAccess` bật (mảng `arr[0]` có thể undefined).
- Mỗi file < 400 dòng, mỗi component < 200 dòng: tách component con trong cùng thư mục nếu cần (đặt tên `XxxParts.tsx` hoặc thư mục con).
- Import kiểu bằng `import type`/`type` inline (ESLint consistent-type-imports). Không `console.log` (chỉ `console.warn/error`).
- Mỗi trang `export default function Page()`.
- Path alias `@/` = `apps/web/src/`.
- Không mock dữ liệu: gọi API thật qua `api`. Mọi query có trạng thái loading/lỗi/rỗng qua `QueryState`.
- Mutation: `useMutation` từ TanStack, sau thành công `queryClient.invalidateQueries`.
- Icon: `lucide-react` (tên icon xem trong build.mjs: L map: home→House, users→Users, calendar→Calendar, trophy→Trophy, book→BookOpen, lock→Lock, store→Store, settings→Settings, wallet→Wallet, search→Search, bell→Bell, chat→MessageCircle, heart→Heart, pin→Pin, plus→Plus, image→Image, link→Link, play→Play, poll→BarChart3 (chart-column), check→Check, down→ChevronDown, right→ChevronRight, ext→ExternalLink, filter→ListFilter, download→Download, mail→Mail, x→X, more→Ellipsis (MoreHorizontal), clock→Clock, file→FileText, qr→QrCode, spark→Sparkles, shield→ShieldCheck, video→Video, globe→Globe, back→ChevronLeft, user→User, send→Send, paperclip→Paperclip, checkcheck→CheckCheck, at→AtSign, megaphone→Megaphone, badge→BadgeCheck, archive→Archive, dollar→CircleDollarSign, copy→Copy, userplus→UserPlus, belloff→BellOff, mailopen→MailOpen).
- Responsive tối thiểu 390px: dùng class `.two-col` (`<div className="two-col"><div className="main">…</div><aside className="rail">…</aside></div>`) cho bố cục 740+312; trên mobile tự xếp dọc. Lưới thẻ dùng `.grid-3`/`.grid-2`. Bảng rộng bọc trong `<div className="table-scroll">`.
